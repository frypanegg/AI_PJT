# 데이터 및 문항 명세

## 입력 데이터 구조

시연용 엑셀 데이터는 하나의 파일에 연도별 Sheet를 둔다.

- Sheet: `2024`, `2025`, `2026`
- A열: 응답형태, 전부 `mail`
- B열: 회사별 법인 코드, 숫자 형식
- C열: 회사명
- D열: 조직명
- E열부터: 문항별 응답
- 1행: 문항 ID
- 2행: 문항 본문
- 3행부터: 응답 데이터

## 응답 척도

객관식 응답은 5개 선택지를 사용한다.

- 전적으로 동의(공감)함
- 동의(공감)함
- 어느 쪽도 아님
- 동의(공감)하지 않음
- 전혀 동의(공감)하지 않음

리포트에서는 아래와 같이 3분류 비중으로 변환한다.

- 긍정: 전적으로 동의(공감)함, 동의(공감)함
- 중립: 어느 쪽도 아님
- 부정: 동의(공감)하지 않음, 전혀 동의(공감)하지 않음

## 실제 채택 객관식 문항 ID

회사가 실제로 채택한 객관식 문항은 아래 32개다. 나머지 문항 Pool은 설문 시스템상 ID가 있더라도 값이 없으므로 분석 대상에서 제외한다.

```text
OS02, OM12, OM11, OM01, CQ01, SD04, SD05, CQ02,
SP45, ER01, RC01, CP11, CQ03, SP12, AV09, JS05,
WE08, JS02, WE12, DM02, CQ04, TW02, TW04, ST01,
TR01, RE01, PE09, DI17, DI12, ER03, DI32, DI20
```

## 주관식 문항 ID

```text
C1: 우리 부서/회사의 긍정적 변화, 자랑할만한 조직문화를 적어주십시오.
C2: 우리 부서/회사에서 개선해야 할 문화, 제도, 정책/관행이 있다면 적어주십시오.
C3: 우리 부서/회사가 일하는 방식 측면에서 개선해야 할 점이 있다면 적어주십시오.
```

## 진단 영역

대분류는 2개다.

- 직원 몰입 수준
- 회사 지원 수준

중분류는 아래 14개다.

- 자발적 몰입
- 방향성 제시
- 리더에 대한 신뢰
- 존경과 인정
- 급여 및 복리후생
- 개발기회
- 실행환경 조성
- 권한/임파워먼트
- 협업
- 업무/구조/프로세스
- 교육훈련
- 가용자원
- 성과관리
- DEIB

## 더미 데이터 설계

시연용으로 3가지 조직 유형을 구성한다.

- 전반적으로 건강한 조직: 긍정 비중이 높고, 일부 보상/자원 영역에서 개선 여지만 존재
- 중립 응답이 많은 변화기 조직: 방향성, 협업, 업무 프로세스에서 판단 유보와 혼선 신호 존재
- 업무방식/자원 개선 신호 조직: 업무환경, 방해 요소, 자원, 프로세스, 피드백 영역에서 부정 비중이 상대적으로 높음
