# AI Agent 및 Subagent 설계

## 기본 방향

하나의 LLM이 모든 일을 처리하는 방식보다, 역할이 분리된 Multi-Agent Workflow로 설명하는 것이 과제의 정교함과 신뢰성을 높인다.

실제 화면에서는 하나의 `조직 건강도 AI Agent`로 보이지만, 내부 설계는 아래 subagent가 순차적으로 협업하는 구조로 제안한다.

## Subagent 구성

### 1. Data Analyst Agent

역할은 계산 정확성이다.

- 연도별 엑셀 파일 읽기
- 실제 채택 32개 문항만 필터링
- 긍정/중립/부정 비중 산출
- 중분류별 집계
- 긍정 Top3, 부정 Top3 도출
- 2024-2026 변화 방향 계산
- 소수 응답 결과 숨김 처리

### 2. Organization Health Interpreter Agent

역할은 조직 건강도 해석이다.

- 문항 해석 사전 기준으로 응답 경향 해석
- 중립 비중이 높은 영역의 의미를 조심스럽게 설명
- 부정 비중이 높은 영역을 리스크 신호로 해석
- 특정 원인 단정 금지
- 조직장 개인 평가처럼 보이는 문장 차단

### 3. Report Writer Agent

역할은 부서장용 리포트 작성이다.

- 2026년 단년 진단 요약
- 긍정/부정 영역 Top3 설명
- 주관식 Top3 요약 반영
- 3개년 변화 분석 문장 작성
- 임원 보고형으로 간결하게 정리

### 4. Action Guide Agent

역할은 처방이 아닌 방향성 제안이다.

- 조직장이 점검해볼 질문 제시
- 다음 30일 대화 주제 제안
- 회의/업무방식/협업 방식 점검 방향 제안
- 제도 개선을 단정하지 않고 확인 포인트 중심으로 안내

### 5. Guardrail Reviewer Agent

역할은 최종 검수다.

- 개인 추정 표현 제거
- 점수, 등급, 순위 표현 제거
- 성과평가/징계와 연결되는 표현 차단
- n 미만 조직 결과 노출 여부 점검
- 단정적 원인 진단 표현 제거

## 시연용 처리 흐름

```text
1. 데이터 검증 완료
2. 응답 비중 산출 완료
3. 조직건강 해석 기준 매칭 완료
4. 2026 리포트 초안 생성 완료
5. 개인정보/표현 가드레일 검수 완료
```

## Tool 구조

실제 구현 시 LLM에게 원천 응답 전체를 직접 계산하게 하지 않는다.

- 계산: Python, 서버 로직, DB 쿼리
- 지식 참조: 문항 해석 사전, 기존 보고서 양식, 조직문화 해석 가이드
- 리포트 생성: LLM
- 출력 통제: 구조화된 출력과 Guardrail
- 보안: 권한 필터링 이후 집계 데이터만 LLM에 전달
