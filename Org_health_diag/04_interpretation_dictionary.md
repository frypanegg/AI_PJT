# 문항 해석 사전 방향

## 온톨로지 대신 문항 해석 사전

현재 단계에서는 OWL/RDF/Knowledge Graph 같은 전문 온톨로지보다, 엑셀 또는 Markdown 기반의 `문항 해석 사전`이 더 현실적이다.

이 방식은 AI 활용 난이도가 낮고, 추후 실제 문항표와 기존 보고서 양식을 반영해 HR 담당자가 직접 관리하기 쉽다.

## 기본 컬럼

문항별 해석 사전은 아래 필드를 권장한다.

```text
문항ID
문항 원문
대분류
중분류
보고서 표시 순서
긍정 응답 해석
중립 응답 해석
부정 응답 해석
3개년 변화 시 해석 포인트
권장 대화 방향
권장 관리 방향
금지 표현
해석 신뢰도
검수 필요 여부
```

## 중분류별 해석 카드 예시

### 협업

- 정의: 부서, 팀원 간 커뮤니케이션과 협력이 잘 이뤄지는가?
- 긍정 비중 높음: 협업 기반이 비교적 안정적으로 인식될 가능성
- 중립 비중 높음: 구성원이나 업무 유형별 경험 차이가 있을 가능성
- 부정 비중 높음: 부서 간 의존 업무, 지원 체계, 커뮤니케이션 흐름을 점검할 필요
- 권장 방향성: 반복 병목, 협업 요청 방식, 의사결정 경로를 확인하는 대화 제안
- 금지 표현: 협업 수준이 낮다, 특정 조직이 비협조적이다, 리더가 문제다

### 업무/구조/프로세스

- 정의: 업무 프로세스 및 조직구조가 합리적으로 갖추어져 있는가?
- 긍정 비중 높음: 구성원이 업무 수행 체계를 비교적 명확하게 인식할 가능성
- 중립 비중 높음: 프로세스 경험이 업무별로 다르거나 체계가 충분히 내재화되지 않았을 가능성
- 부정 비중 높음: 의사결정, 역할 경계, 업무 흐름의 병목을 확인할 필요
- 권장 방향성: 반복되는 지연과 재작업 구간을 확인하는 대화 제안
- 금지 표현: 조직 구조가 비효율적이다, 프로세스가 잘못됐다

### DEIB

- 정의: 모든 직원이 존중받고 공정한 대우를 받으며 소속감을 느낄 수 있는 환경인가?
- 긍정 비중 높음: 존중, 공정성, 포용 경험이 비교적 안정적으로 인식될 가능성
- 중립 비중 높음: 구성원 집단별 체감 차이가 있거나 경험이 명확히 형성되지 않았을 가능성
- 부정 비중 높음: 공정성, 발언 기회, 포용 경험을 점검할 필요
- 권장 방향성: 회의 발언 기회, 정책 적용 일관성, 기여 인정 방식 확인
- 금지 표현: 차별이 있다, 포용성이 낮다, 특정 집단이 불만이다

## 해석 문장 원칙

좋은 문장:

```text
협업 관련 문항에서 부정 응답 비중이 상대적으로 높게 나타났습니다.
이는 업무 프로세스, 역할 경계, 부서 간 의존성에서 구성원이 불편을 경험했을 가능성을 시사합니다.
다만 특정 원인을 단정하기보다는, 반복적으로 지연되는 업무와 의사결정 병목을 확인하는 대화가 필요합니다.
```

피해야 할 문장:

```text
협업 수준이 낮습니다.
조직장이 협업 관리를 못하고 있습니다.
이 부서는 문제가 있습니다.
점수가 낮아 개선이 필요합니다.
```
