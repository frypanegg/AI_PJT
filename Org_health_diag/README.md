# 2026 조직건강도 AI Agent

연도별 조직 건강도 설문 결과 엑셀을 기반으로, 부서장이 **본인 담당 조직의 진단 결과를
스스로 해석하고 구성원과의 대화 주제를 찾도록** 돕는 웹 애플리케이션이다.
HR 관리자·경영진용 관리자 화면을 별도로 제공한다.

시연은 사외 환경에서 합성 더미 데이터를 사용한다. 실제 사내 적용 시에는 SSO, 권한 관리,
접근 로그, 소수 응답 보호, 개인 응답 미노출 등 보안 통제가 전제된다.

## 핵심 원칙

> **이 화면이 누군가를 평가하는 데 쓰이지 않는다.**

기능을 더할지 판단이 설 때마다 이 기준으로 되돌아갔다. 점수를 넣지 않은 것도,
부서 간 비교를 없앤 것도, 개인을 특정하려는 질문을 거절하는 것도 같은 이유에서 내린 결정이다.

- 최신 연도 진단 결과를 메인 장표로, 연도별 변화 분석은 보조 장표로 제공한다.
- 평가 점수·등급·순위는 제공하지 않고, 긍정/중립/부정 **응답 비중**만 보여준다.
- 부서장 화면의 비교는 **우리 부서 내부 영역 간 비교**로 한정한다(부서 간 비교 지양).
- AI는 평가자가 아니라 보수적 해석자, 리포트 작성자, 대화 촉진자 역할을 한다.

## 빠른 시작

```bash
cd Org_health_diag/webapp
pip install -r requirements.txt
uvicorn main:app --port 8000
```

접속: <http://localhost:8000> (DB가 비어 있으면 기동 시 더미 데이터를 자동 적재한다)

계정 정보는 `streamlit_app/DEMO_GUIDE.md` 참조.

## 데이터

더미 데이터는 하나의 엑셀 파일 안에 연도별 시트(`2024`·`2025`·`2026`)를 갖는다.

- A열 응답형태 / B열 법인코드 / C열 회사명 / D열 조직명
- E~AJ열 객관식 32문항 / AK~AM열 주관식 3문항
- 1행 문항 ID, 2행 문항 본문, 3행부터 응답 데이터

**연도는 코드에 고정되어 있지 않다.** 시트 이름에서 4자리 연도를 자동 인식하므로,
내년에 `2027` 시트가 추가된 파일을 업로드해도 코드 수정 없이 전 화면이 확장된다.

시연용 조직은 포스코·포스코이앤씨 각 3개 부서(총 6개)이며, 3가지 조직 유형
(건강한 조직 / 변화기 조직 / 개선 신호 조직)을 두 회사에 배정했다.
전체 객관식 긍정 응답 비중은 실제 조직문화 설문과 유사하게 50% 이상이 되도록 설계했다.

> 6개 조직 중 3개는 합성 복제본이며, 중분류별 편차도 시연 가독성을 위해 인위적으로
> 주입한 것이다. 실제 설문 결과가 아니다. 자세한 내용은 `SYSTEM.md` §4 참조.
