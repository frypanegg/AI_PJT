# Org Health Diagnosis AI Agent

## 프로젝트 개요

이 프로젝트는 회사의 연도별 조직 건강도 설문 결과 엑셀 파일을 기반으로, 부서장 개인에게 본인 담당 조직의 조직 건강도 진단 결과와 AI 기반 인사이트를 제공하는 웹 페이지 데모를 만드는 것을 목표로 한다.

시연은 사외 환경에서 더미 데이터를 사용한다. 실제 사내 적용 시에는 SSO, 권한 관리, 접근 로그, 소수 응답 보호, 개인 응답 미노출 등 보안 통제가 전제된다.

## 핵심 방향

- 2026년 1개년 진단 결과를 메인 장표로 노출한다.
- 2024-2026 3개년 변화 분석은 추가 장표로 제공한다.
- 실제 평가 점수, 등급, 순위는 제공하지 않는다.
- 기존 보고 방식과 같이 긍정/중립/부정 응답 비중을 중심으로 보여준다.
- AI는 평가자가 아니라 보수적 해석자, 리포트 작성자, 대화 촉진자 역할을 한다.

## 데모 데이터

더미 데이터는 하나의 엑셀 파일 안에 `2024`, `2025`, `2026` 세 Sheet를 포함한다.

- A열: 응답형태, 전부 `mail`
- B열: 회사별 법인 코드, 숫자 형식
- C열: 회사명
- D열: 조직명
- E~AJ열: 객관식 32문항 응답
- AK~AM열: 주관식 3문항 응답
- 1행: 문항 ID
- 2행: 문항 본문
- 3행부터: 응답 데이터

시연용 조직 유형은 3가지로 구성했다.

- 전반적으로 건강한 조직
- 중립 응답이 많은 변화기 조직
- 업무방식/자원 쪽 개선 신호가 있는 조직

전체 객관식 긍정 응답 비중은 실제 조직문화 설문 자료와 유사하게 50% 이상이 되도록 설계했다.
