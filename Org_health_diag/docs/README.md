# 프로젝트 산출물 (docs)

프로젝트 수행 결과를 정리한 최종 산출물 2종과, 그것을 다시 만들 수 있는 생성 스크립트를 담고 있다.

## 산출물

| 파일 | 내용 |
| --- | --- |
| `2026_조직건강도_AI_Agent_수행결과.pptx` | 컨설팅 보고서 형식의 수행 결과 보고서 (16장) |
| `demo/2026_조직건강도_AI_Agent_시연.mp4` | 타이틀·간지·자막을 넣은 시연 영상 (1920×1080) |

## 재생성 방법

두 산출물 모두 실행 중인 앱에서 화면을 직접 가져오므로, 먼저 웹앱을 띄워야 한다.

```bash
cd Org_health_diag/webapp && uvicorn main:app --port 8000
```

### 보고서 (PPTX)

```bash
cd Org_health_diag/docs
npm install pptxgenjs      # 최초 1회
node build_deck.cjs
```

`shots/` 의 화면 캡처를 슬라이드에 넣는다. 화면이 바뀌었다면 캡처부터 다시 뜬다.

### 시연 영상 (MP4)

```bash
cd Org_health_diag/docs/demo
python record_demo.py
```

- `overlay.js` 를 앱 페이지에 주입해 타이틀 카드·챕터 간지·자막·커서를 얹는다.
  별도 플레이어를 iframe으로 띄우면 `file://` ↔ `http://` 교차 출처 때문에 내부 제어가
  막히므로, 앱 페이지 위에 고정 레이어를 직접 올리는 방식을 썼다.
- 페이지 이동(로그인 → 리포트) 중에도 간지와 자막이 끊기지 않도록 오버레이 상태를
  `sessionStorage` 에 두고 새 문서에서 즉시 복원한다.
- Playwright로 1600×900 녹화 후 ffmpeg로 1920×1080 H.264로 인코딩한다.

## 구성 요소

```
docs/
├── 2026_조직건강도_AI_Agent_수행결과.pptx   보고서 (산출물)
├── build_deck.cjs                          보고서 생성 스크립트
├── shots/                                  보고서에 넣는 화면 캡처 9장
└── demo/
    ├── 2026_조직건강도_AI_Agent_시연.mp4    시연 영상 (산출물)
    ├── record_demo.py                      영상 시나리오 + 녹화 드라이버
    └── overlay.js                          타이틀·간지·자막·커서 오버레이
```
