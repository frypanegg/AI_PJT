# 시연 진행 안내 (진행자 전용)

로컬 PC 시연용 자료입니다. 아래 인증코드는 화면에 노출되지 않으며,
개인별 안내 메일 본문에 진행자가 직접 포함해서 전달하는 것으로 가정합니다.

## 1. 실행 방법

```bash
cd Org_health_diag/streamlit_app
pip install -r requirements.txt
streamlit run app.py
```

기본 접속 주소: `http://localhost:8501`

### 1-1. (선택) 챗봇 웹검색 Tool 활성화

5번 섹션 챗봇은 14개 진단 영역과 무관한 일반 리더십/조직관리 질문을 받으면 Tavily로
웹을 검색하고 OpenAI 모델로 종합해 답변을 시도한다 (`web_advisor.py`). `OPENAI_API_KEY`와
`TAVILY_API_KEY`가 둘 다 없으면 이 기능은 자동으로 비활성화되고, 14개 영역 관련 답변은
이 키 없이도 그대로 동작한다.

키는 두 가지 방법 중 하나로 제공하면 된다.

1. **상위 폴더 `.env` 자동 인식(권장, 이미 설정되어 있음)**: `프로젝트과제/.env`에
   `OPENAI_API_KEY`, `TAVILY_API_KEY`가 있으면 앱이 자동으로 읽는다. 별도 설정 불필요.
2. **`secrets.toml` 직접 설정**:
   ```bash
   cd Org_health_diag/streamlit_app/.streamlit
   cp secrets.toml.example secrets.toml
   # secrets.toml을 열어 OPENAI_API_KEY, TAVILY_API_KEY 값을 채워 넣는다
   ```

`secrets.toml`은 `.gitignore`에 등록되어 있어 git에 올라가지 않는다. 이 기능은 인터넷
연결과 OpenAI/Tavily API 사용 비용이 필요하다.

### 2-1. 관리자(Admin) 계정

## 3. 시연 스토리라인 참고

더미 데이터는 3가지 조직 유형으로 설계되어 있고 (`01_project_concept.md`,
`02_data_and_question_spec.md` 참고), 이를 두 회사에 각각 배정했다. 회사당 1개 유형은
다른 회사의 응답 패턴을 약하게 변형(jitter)한 합성 복제본이다
(`dummy_data/build_extended_dataset.py` 참고).

- 철강사업실(포스코) / 철강설계실(포스코이앤씨, 복제): 전반적으로 건강한 조직
- 기술기획실(포스코) / 플랜트설계실(포스코이앤씨, 복제): 중립 응답이 많은 변화기 조직
- 건설전략실(포스코이앤씨) / 경영혁신실(포스코, 복제): 업무방식/자원 개선 신호 조직
  (가용자원·성과관리·업무구조프로세스 부정 비중 높음)

## 4. 구현된 Guardrail (06_guardrails.md 대응)

- 점수/등급/순위 미표시, 긍정·중립·부정 비중만 노출
- 주관식 원문 대신 반복 경향 기반 Top3 요약만 노출
- 소수 응답 조직 결과 숨김 처리 (`auth.MIN_RESPONDENTS`, 현재 더미 데이터는 전 조직이 기준 이상)
- 로그인/로그아웃 접근 이력 로컬 기록 (`streamlit_app/logs/access_log.csv`)
- AI 해석 문장은 금지 표현을 배제한 템플릿 기반 로직으로 생성 (`insights.py`)
- 5번 섹션의 대화형 챗봇은 14개 진단 영역 질문에 대해서는 외부 API 호출 없이 완전히
  로컬에서 동작 (`chatbot.py`), 조직의 집계 데이터만 응답에 사용하고 개인 원문은 참조하지
  않음. 영역과 무관한 일반 리더십 질문은 (API 키 설정 시) 질문 문장만 웹검색 Tool로
  전달되며, 이 경우에도 조직 진단 데이터는 전달되지 않음 (`web_advisor.py`)
- 리포트 하단 "리포트 보관하기"에서 요약·챗봇 대화 기록을 담은 HTML 파일을 다운로드 가능
  (`report_export.py`). 사내 메일 서버 연동은 되어있지 않아, 다운로드한 파일을 본인이 직접
  메일에 첨부하는 방식이다.
- **관리자 화면은 부서장용 화면과 guardrail 적용 범위가 다르다.** 부서장 화면(1~5번 섹션)은
  "조직 간 순위 제공 금지" 원칙을 지키지만, 관리자 화면은 HR 관리자·경영진이 부서 간 상태를
  비교/점검하는 것이 본래 목적이므로 전사 평균 대비 우수/관심 필요 구분을 의도적으로 제공한다
  (점수·등급은 여전히 미제공). 06_guardrails.md의 "부서장은 본인 조직만 조회" 원칙에 따라
  이 화면은 별도 관리자 계정으로만 접근할 수 있다.

## 5. 알려진 제한사항 (MVP 범위)

- AI 리포트 문장은 실시간 LLM 호출이 아니라, 문항 해석 사전 기반 규칙 로직으로 생성한 예시입니다.
  실제 적용 시 `03_ai_agent_design.md`의 Multi-Agent 파이프라인(LLM 기반 Report Writer/Guardrail
  Reviewer)으로 교체하는 것을 전제로 합니다.
- 응답률(%)의 "대상 인원"은 더미 데이터에 없는 값이라 데모용 가정치를 사용했습니다 (`auth.py`
  `target_headcount`). 화면에도 "가정치"로 표기됩니다.
- 인증은 SSO가 아닌 조직+생년월일 6자리 데모 로직입니다. 실 서비스 전환 시 06_guardrails.md의
  SSO/권한 매핑 요건이 적용되어야 합니다.
- 챗봇의 14개 영역 관련 답변은 자유 대화형 LLM이 아니라 키워드 매칭 기반 규칙 응답입니다.
  영역과 무관한 일반 리더십 질문은 API 키가 설정된 경우 Tavily 검색+OpenAI 종합 Tool로 답변하고,
  키가 없거나 검색이 실패하면 선택 가능한 주제 목록으로 안전하게 대체됩니다. 실제 적용 시
  03_ai_agent_design.md의 Action Guide Agent로 완전히 교체하는 것을 전제로 합니다.
- 포스코이앤씨(6개 조직 중 3개)와 포스코(3개 조직 중 1개)는 각각 다른 회사의 원본 응답 패턴을
  복제·jitter한 합성 데이터입니다. 실제 서로 다른 두 회사의 응답이 아니라는 점에 유의하세요.
