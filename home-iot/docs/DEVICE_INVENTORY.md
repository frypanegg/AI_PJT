## 조명 경로

```
home-core → HA → Matter 가상스위치 → Aqara M2 허브 → Zigbee → E1 스위치
```

전 구간 로컬이다. 클라우드도, 추가 하드웨어도, 재페어링도 필요 없다.

## 한계 1 — 조명 상태를 읽을 수 없다

씬은 단방향이다. E1 스위치가 지금 켜져 있는지 HA 로 되돌아오는 경로가 없다.
씬 스위치 자체는 실행 후 `off` 로 복귀하므로 **그 값을 상태로 쓰면 안 된다.**
레지스트리에서 `entity_id` 를 비워 이 능력을 `readable: false` 로 두는 이유다.

해결하려면 둘 중 하나가 필요하다.

- **Aqara 클라우드 연동** — 계정 연결만 하면 되지만 로컬이 아니게 된다.
- **Zigbee2MQTT** — 완전 로컬이고 상태도 읽히지만, E1 을 M2 허브에서 떼어내
  재페어링해야 한다.

## 한계 2 — 거실1 / 거실2 개별 제어 불가

기존 씬 구성이 거실1만 담고 있었고, 새 씬도 같은 구성으로 맞췄다. 나누려면
Aqara 앱에서 씬을 4개 더 만들고 레지스트리에 기기를 2개로 쪼개면 된다.

## 한계 3 — LG "남은 시간"은 시각이다

`sensor.*_finish_time` 은 남은 분이 아니라 ISO 종료 시각(`2026-09-13T10:20:51+00:00`)
이다. 레지스트리에서 이름을 `finish_at`, 타입을 `timestamp` 로 두고 주석을
남겼다. 숫자로 뭉개면 LLM이 "3시간 남았다"를 "2026분 남았다"로 답한다.
